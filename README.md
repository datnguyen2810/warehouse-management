# 🏢 Hệ Thống Quản Lý Kho Vật Tư (Warehouse Management System)
Dự án Bài tập lớn môn Lập trình Web.
---
## 🛠️ Công nghệ sử dụng
- **Backend:** Java 17 / 21, Spring Boot (Spring MVC, Spring Data JPA, Spring Security)
- **Frontend:** JSP, JSTL, HTML5, CSS3, JavaScript
- **Database:** MySQL
- **Build Tool:** Maven (Maven Wrapper đi kèm)
---
## 🚀 Hướng dẫn cài đặt và khởi chạy
### 1. Yêu cầu hệ thống
- JDK 17 trở lên
- MySQL Server (Port mặc định: 3306)
